# 06 辅助工具（assist/）

出题前期的**站对表准备工具**。与五步主线（step1~5）解耦：只读 railway.db、
只写输出 xlsx，不参与测评链路，也不触任何 LLM。

## 1. filter_pairs_by_direct.py —— 按直达车次数随机采样站对表

### 用途

控制题面直达难度：生成直达车次数落在指定区间的站对表（2.xlsx 同构），
直接作为 `step2_generate.py --stations` 的输入。
例：换乘题配「直达 0 趟」的站对（防直达逃逸干扰难度）、直达题配「直达 3~5 趟」
的站对等。

### 算法：先穷举统计，再按区间精确筛选（无命中率问题）

```
① 先举：一次遍历全库经停，穷举统计每个有序站对（同车 A 先于 B）的
   直达车次数 → 约 10 万条字典，秒级；
② 再抽：每个区间（min≥1）从统计中筛选 k∈[min,max] 的候选（排除已收对，
   跨区间全局去重），随机抽取 --counts 个——候选池是全量事实，
   **高直达区间也必然收满**；候选不足则全收并 ⚠️ 提示；
③ min=0 区间（无直达）：候选不在穷举统计里，走随机站对法（随机对
   绝大多数为 0 直达，近乎必中），预算 = 个数 × --attempts-multiplier。
④ 后写：分块输出（见下）。
```

- **跨区间全局去重**：同一有序站对只会归入一个区间（含方向）。
- **直达数口径**：同一车次经停表中 A 出现在 B 之前的 distinct 车次数。
  **与出题端 `get_routes_between` 完全一致**——不去重同车多号（未跑 cleanup
  时双号车计两次），保证与出题/模型实际看到的口径相同。
- 全库分布参考：[100,200]仅 22 对、[60,99]130、[40,59]288、[20,39]1321、
  [10,19]3854、[2]17180、[1]57118——高直达区间请按此设置合理个数。

### 参数（除 --seed 外全部必填）

| 参数 | 说明 |
|---|---|
| `--railway-db` | 基础数据库路径（只读） |
| `--ranges` | 直达数区间列表：**逗号分隔**（`\|` 是 cmd 管道符，不加引号会被拆开）、`~` 连接上下限，如 `0~10,20~60,100~200`（允许 min=0 与 min==max） |
| `--counts` | 每区间输出个数：逗号分隔，**个数必须与 --ranges 一致**，如 `10,20,30` |
| `--attempts-multiplier` | 仅 min=0 区间使用：尝试上限 = 该区间个数 × 此倍数（≥1；min≥1 区间走穷举筛选，无命中率问题） |
| `--out` | 输出 xlsx 路径（父目录自动创建） |
| `--seed` | 随机种子（可复现；缺省每次随机） |

### 用法示例

```
python assist/filter_pairs_by_direct.py --railway-db data/railway.db ^
    --ranges 0~10,20~60,100~200 --counts 10,20,30 ^
    --attempts-multiplier 300 --out 2_站对表.xlsx --seed 42
```

### 结束语义

- **min≥1 区间**：穷举统计后精确筛选，**必然收满**——除非该区间候选池本身
  不足（如 100~200 全库仅 22 对而要 50 个），此时输出全池并 ⚠️ 提示。
- **min=0 区间**：随机站对法近乎必中；仅当候选被去重耗尽（极端）才会打满
  预算警告。
- 控制台逐区间打印候选池/抽取数（min=0 区间打印尝试/命中率），
  并逐对列出（站名 + 直达数）供人工核对。

### 输出格式（分块 + 元数据行）

```
出发站 | 到达站 |      | 范围     | 个数     ← 表头（第 4/5 列写字）
      |      |      | 0~10    | 10      ← 第 1 类元数据行（在该类上方）
A站   | B站   |      |         |         ┐
…     |      |      |         |         ┘ 第 1 类 10 行
      |      |      | 20~60   | 20      ← 第 2 类元数据行
…     |      |      |         |         ┘ 第 2 类 20 行
      |      |      | 100~200 | 30      ← 第 3 类元数据行
…     |      |      |         |         ┘ 第 3 类 30 行
```

- 每个区间 = 一行**元数据行**（前 2 列空、第 4 列=范围、第 5 列=实际收集个数）
  在该类数据行上方。
- **读入端配套**（`parse_stations_xlsx`）：只读前 2 列，第 3 列及以后忽略；
  前两列皆空的行（含元数据行）视为空行，连续 1~3 个跳过继续，**连续 ≥4 个
  视为表结束**；表头自动跳过。step2 可直接消费此类含元数据的站对表。
